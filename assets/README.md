# TrueTone logo

The speech bubble represents spoken language; the waveform represents vocal delivery. Forest green, ivory, and a terracotta accent match the interface. Keep the icon square and preserve its proportions.

- `logo.png`: generated master.
- `logo-96.png`: website header.
- `logo-192.png`: native startup screen and reusable web icon.
- `apple-touch-icon.png`: 180 px web shortcut icon.
- `favicon.ico`: browser icon, including 16, 32, and 48 px sizes.
- `TrueTone.icns`: macOS Finder and Dock icon.

Created with the built-in image generation tool. Prompt: “A premium minimal TrueTone app icon: an ivory speech bubble containing a waveform on a forest-green rounded square, one terracotta waveform accent, readable at small sizes, no text or watermark.” Final refinement preserved the symbol and required a solid opaque forest-green background.
